# 库外照片与施工图落位

新分支，不合并，也不覆盖之前的选配骨架。

## 做到了

- 客户可以在示例库之外上传一两张产品照片，确认品类后，在已经定好的房间部位里看一件示意模型。马桶、软装沙发、开关插座都可以，柜、灯、门、厨电也同样。
- 做法是把照片贴在这一类的常用外形上，尺寸用填写的毫米数，不填就用该类常用尺寸。不重建细部。只上传一张时，背面仍是常用外形。
- 固定视角（正视、斜向、靠近某一件）和可旋转的房间都能看见。刷新后还在。
- 页面和报价单都写明：仅用于效果展示，不列入采购。部位合计不随照片变化，也不能下单。承诺只写到：外形接近、能看出来是同一类、同一款式方向。并写明这不是付费重建的质量。
- 演示方案里已经放了公卫马桶和客厅沙发两张示意图，不用另找文件就能点开。
- 管理端公布了给设计院的图纸交付要求：分层、关掉尺寸文字家具机电、墙线闭合、单位和比例、优先矢量，不要杂乱扫描件。
- 工程师可上传简化平面（PDF、图片、SVG、DXF），在图上点客厅、卫生间、马桶位、墙和地。系统按这些点摆已经挂上的产品和材料。A 户型有一张演示图和一批点。
- SVG 和 ASCII DXF 会抽出线段，房间里按这些线做示意墙。图片只作底图。PDF 只保存，不转成底图。
- 房间里的地面、墙面、天花用了程序贴图，并加了灯槽、阴影和更柔和的光。仍标明是示意，不是施工图对齐。

## 仍是占位

- 没有调用任何付费出图或图生三维。代码里留了一个不会被调用的函数，不读取密钥。
- 整张 DWG 的分层不解析。二进制 DXF 也读不出线。
- 户型「识别」按钮仍然不读图。点选是人工标注，不是自动识别。
- 产品库的图仍是示意图，不是品牌实拍。演示用的两张效果图也是示意图；只有客户自己上传的才是照片。
- 三维房间不是按施工图或 CAD 坐标对齐。墙线来自简化图的轮廓，比例是示意的。
- 单张照片看不清背面和细部。开关在画面里会略放大，方便看清。

## 本地怎么点

启动方式见仓库 README。客户 `13800138000` / 验证码 `123456`。管理端 `admin` / `demo1234`。项目 `GZ2019-003`，A 户型。

1. 客户登录，点已有方案，进入九类选配。
2. 切到「房间落位」。点正视、斜向、看马桶、看沙发、旋转。注意「仅用于效果展示，不列入采购」，以及底部合计没有把这两件算进去。
3. 切回「材质」，沙发外观来自那张示意图。
4. 页下「用照片看效果」再传一张开关照片，确认品类。合计仍不变。
5. 管理端打开该项目，拉到「施工图落位」，读交付要求，在已有的简化平面上再点一个部位。
