# 看得出规模这一版

分支 `cursor/fitout-prototype-scaffold-1b90`，不合并。

## 做到了

- 客户选配九类并列，先点大项，再进方案或房间，再逐件。每件有示例图和数量；灯具、开关插座保留国产/进口。报价仍随勾选变化。
- 示例产品库：九类各 36 个自制 SKU，多个示例品牌，带尺寸、国产价、进口价和示意图。
- 手册 PDF 和图包 zip 可导入，先进入待确认，确认后客户才选得到。示例文件在 `packages/catalog/samples/`。
- 项目页可按户型、房间、部位把库内型号挂到项目。
- 房间落位用通用方块按尺寸放进 A/B 户已有房间。另有两件自制 GLB（门分门框/门扇，柜一块）可旋转、换色。可上传 glTF、GLB、FBX、OBJ。
- 生模接口只登记任务并按品类尺寸入库，不发出付费请求。

## 仍是占位

- 房间位置按面积排成格子，不是 CAD 或施工图对齐。
- 产品图是程序绘制的示意图，不是品牌照片，名称都带「示例」。
- 没有识别他人效果图，也没有爬取品牌官网。
- 户型图「识别」仍不读图。
- 通用件在三维里是按尺寸缩放的方块，不是曲面洁具或灯具细模。
- 付费生模、即梦、通义、豆包都没有调用。
