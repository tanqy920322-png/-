# 精装选配操作说明

这份说明给建筑和精装工程师。按下面的顺序点，大约一到两天可以独立做一户试点。页面上的品牌和图片都是系统自带的示例，不是厂家实拍，也不能当成在售商品。

## 1. 登录后台

打开管理端登录页，账号 `admin`，密码 `demo1234`。

客户不走这个入口。客户用手机号登录选配，看不到一户一档。

## 2. 新建项目

左侧点「项目」，再点新建。

填写项目编号、名称、城市和开发商。编号用字母和数字，例如楼盘内部编号。建好后先保持草稿，核对完再发布。发布之后，客户登录才能在列表里看到这个项目。

已经建好的演示项目是 `GZ2019-003`，可以直接拿来练习，不必另建。

## 3. 上传图纸

打开项目，找到对应户型。

点「上传图纸」，类型选平面图或用量图，选中户型，再选择电脑里的 PDF、图片或 DWG。上传后，这条图纸会记在该户型下面。

「识别户型」不会读图，也不会改房间。房间名称和面积在建户型时已经写好。

要落位，请用同一页下方的「施工图落位」，不要指望识别按钮。

## 4. 把部位和产品挂到项目

仍在项目页，往下找到「部位挂品」。

1. 选户型。
2. 选房间。天花、墙面、地面请分别做一次。入户门可以选「整户」。
3. 选部位。
4. 在示例产品里选一个型号。列表里能看到国产价和进口价。
5. 点「挂到项目」。

挂上之后，客户选到这个房间的这一类时，会看到你挂的示例图和价格。换一个型号再点一次，就会覆盖原来的。

## 4.1 施工图落位（人点，系统摆）

仍在项目页，找到「施工图落位」。先读上面的交付要求，再拿去跟设计院要图：

- 墙、柱、门、窗、房间范围分图层，房间范围要闭合，并写上房间名。
- 出这张图时关掉尺寸、文字、家具和机电。
- 墙线闭合，门窗洞留开口。
- 写清单位和比例。
- 优先 CAD 导出的 PDF、SVG、DXF，或干净图片。不要杂乱扫描件。
- 整张 DWG 的分层自动读取这一轮不做。DWG 仍可当档案上传，落位请另交简化图。

演示项目 A 户型已经放了一张简化平面，上面有客厅、公卫、马桶位等点。可以直接看「按这些点摆上的产品和材料」。

自己练习：选户型，上传 PDF、图片、SVG 或 DXF，在图上点一下，选房间和部位（例如公卫、马桶），再点「记下这个点」。客户打开「房间落位」时，会按当前这张图上的点摆已挂的产品和材料。这不是自动识别，也不是按施工图对齐。

PDF 只保存文件，不转成底图，点选落在空白底上。DXF 能抽出线段就画出线；抽不出就仍可点选。图片可以当底图点，但不会变成墙线。

## 4.2 内部样板和示意贴图

左侧点「内部样板」。这是祺盛内部评测用的资料，页面上写着：非授权经销清单，不对外展示、不作客户承诺。

这里有 20 条公开页核过的样板。全屋定制按实际尺寸定制，不按单一零售型号陈列。欧派是量尺定制，没有型号，也没有尺寸。Nobilia 只保留官方类型表模块 U60 的 600×561×720 mm，标明供按实际尺寸定制对照。正泰仍是「未找到可核验公开资料」，不补型号，也不写成 86 型。没有官方单品图的，页面上就不放图。

天花、墙面、地面各两张，用资料包里的官方图做房间里的示意贴图。客户选配页可以切换这几张贴图看效果，报价不变。贴图旁边写着「示意贴图，不是品牌实拍」。

生模这一栏是「未完成」。六件待评清单的状态都是「未接免费接口」。确认入库的队列是空的。没有接付费生模，客户点选也不会去生成模型。

## 5. 从产品库选品

左侧点「产品库」。

每一类都有一批示例型号，带尺寸和两种价格。图是系统画的示意图，角上标着「示例」。

如果设计院有自己整理的手册：

1. 点「下载示例手册」或「下载示例图包」，先看文件长什么样。手册是 PDF，图包是压缩包，里面有一张清单。
2. 用同样的格式准备文件后，在产品库页面上传。
3. 新读入的型号先出现在「待人工确认」。核对名称、规格和价格。
4. 点「确认入库」。确认之前，客户选不到它。

不要把从品牌官网下载的图片或手册传进来。

## 6. 客户那边怎么看

让客户用手机号登录，验证码演示环境是 `123456`。演示客户 `13800138000` 已经有一套方案。

客户路径：选项目和户型 → 选风格 → 进入九类选配。

九类是一样大的入口：天花、墙面、地面、全屋定制、洁具、入户门、厨房电器、灯具、开关插座。点进某一类，再选方案或房间，最后逐件勾选。每一件有示例图和数量。灯具、开关插座还可以选国产或进口。

勾选或换型号后，页面底部的合计会变。

三维里，「材质」表现天花、地面、墙面。若客户上传了沙发照片，客餐厅沙发会贴这张照片。「房间落位」按简化平面上的点摆柜、灯、门、洁具和照片效果件。没有点选的户型仍按房间格子示意。两种都不是施工图对齐。

客户可以用自己的照片看马桶、沙发、开关等件的效果。页面写明：仅用于效果展示，不列入采购。报价合计不会因为这张照片变化。一户一档里能看到这些照片，同样不进报价。

## 7. 看模型

产品库页面下方可以打开仓库里的示例门、示例柜，也可以上传 SketchUp 导出的 glTF、GLB、FBX 或 OBJ。拖动旋转。门框和门扇如果分成了两块，可以分别上色。

「按尺寸入库」不会连接付费的生模服务。它只按品类的常用尺寸做一件通用模型，放进产品库，房间落位里按这个尺寸显示。

## 8. 看一户客户的档案

左侧「客户方案」打开某一户。这里能看到风格、报价，以及房间和件数。这个页面只在管理端。
