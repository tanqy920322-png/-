## 网格放哪里

GLB 五件合计大约 126MB，不要提交进 git。元数据和预览图在仓库里。程序只在本地找网格，找不到就在管理端写明缺哪个文件，页面照常打开。

验收包解压后的文件夹名是 `生模评测`。里面直接放上述 `.glb`，不要再套一层型号目录。

按这个顺序查找：

1. 环境变量 `QISHENG_MESH_DIR` 指向的文件夹（文件夹本身，不是某一个 glb）。
2. 仓库根目录下的 `生模评测/`。
3. `packages/catalog/internal-sample/生模评测/`。
4. 启动 API 时的当前目录下的 `生模评测/`。

例如把验收包解压到仓库根目录：

```bash
# 解压后应能看到：生模评测/HC0508PT.glb
ls 生模评测/HC0508PT.glb
```

或者不放进仓库：

```bash
export QISHENG_MESH_DIR=/绝对路径/生模评测
```

这两个位置都已写进 `.gitignore`。预览图不依赖 GLB。没放文件时，内部样板仍显示 5 件和预览图，网格一栏说明已查找的路径。

## 再发起一次生模

管理端「产品库」和「内部样板」都有生模入口。设计师上传图册（PDF、ZIP）或产品图（PNG、JPG、WEBP）后点「发起生模」。

免费资源包已经用尽，后付费没有开通。入口会把这次上传记下来，然后停住。接口状态是 `blocked`，`paid_api_called` 为 false。不会调用付费图生三维，不会读取或写入付费密钥，也不会开通后付费、购买积分包、充值或绑定支付。

随验收包来的说明记的是那一批评测当时的积分情况。现在系统按已拍板的事实处理：这 5 件已经确认入库；再生成会因额度不足停住。
