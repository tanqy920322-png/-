# 面客系统 · 内部样板产品库（评测用）

本目录是给面客系统做内部样板和免费图生 3D 评测用的资料库，**不是品牌授权、经销或合作清单**。所列型号、尺寸和图片均摘自 2026 年 11 月 11 日查阅的公开产品页或官方目录，只供内部对照，不对外展示、不作为对客户的承诺，也不表示已与这些品牌签约。

- 没有编造型号或尺寸。官网未写明的字段一律留空。
- 没有编造价格。官网没有明确零售价的，一律不填。
- 图片仅供内部评测。已下载的官方产品图放在 `images/`，文件名格式为「品类-品牌-型号」。表格中的 `image_url` 是原图来源，`local_image` 是本地路径。
- 未注册任何云账号，未调用任何生模或出图 API，也未编写爬虫或批量遍历品牌整站。每一条都是针对具体产品页或官方目录逐条打开核验的。
- 未把受版权保护的手册原文写入本库，只摘了型号、名称、尺寸或规格，以及来源链接。

## 缺项（请明天对账时一并过目）

1. **欧派**：官网橱柜为量尺定制，未找到可核验的单一型号和毫米尺寸。未改用其他品牌。
2. **正泰**：正泰居家官网只有 NEW2 系列介绍，没有可核验的具体型号和尺寸。未采用第三方网站上的型号。
3. **Duravit**：优先想收马桶本体，但部分专业库链接本次核验为 404；现收的是已核验的 D-Neo 座圈。TOTO 马桶已作为第 3 条备选补上。
4. **Hörmann ThermoSafe**：定制门，官方页未给出单一标准宽高。
5. **友邦 EF1020、雷士缥缈系列、施耐德、西门子**：型号已核验，但尺寸或轴向不完整，已留空或在 notes 中写明，没有猜。
